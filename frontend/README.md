# Frontend inicial
React y TypeScript. Esta pantalla es una base de estructura; no permite todavía autenticarse ni gestionar turnos.
Desde frontend/: npm install, luego npm run dev. Para compilar: npm run build.
No guardar claves externas de Notificaciones en el código web. El frontend final usará el gateway y credenciales del usuario.
Versiones iniciales fijadas en package.json; generación de package-lock.json, instalación y compilación están pendientes porque esta sesión no dispone de acceso de red para instalar dependencias.
